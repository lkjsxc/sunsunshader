# Sunsun Shader 0.2.0-rc6

Sunsun rc6 is for Horizon Nightly 2026-11-19 (5ef7734) with shader API 0.2. Place the archive in the game's `shaderpacks/` folder and select Sunsun Shader.

- Trial spawners keep emitted haze on the cage's own block when **Light in the air** is enabled. This removes detached lobes from the waiting, active and ominous states.
- Vanilla lanterns and soul lanterns distinguish the dark iron frame from the bright glass. The effect fades into distance between 12 and 24 blocks.
- **Light in the air** is off by default. Enable it in Medium or High for local light scattering. Atmospheric sky and fog remain part of the pack.

The release archive passed the pinned Nightly validator, ordinary-game admission and negative admission checks. Matched Radeon captures exercised the spawner and lantern changes separately. Radeon timings for the new default are pending.
